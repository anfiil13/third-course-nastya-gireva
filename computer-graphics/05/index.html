Краткое объяснение

Flood Fill

Начинает обход с seed-точки и распространяется по четырём соседям. Клетки контура и уже посещённые клетки пропускаются. Используется явный стек, а не рекурсия.

Scanline Fill

Для каждой строки ищет пересечения с непараллельными горизонтали рёбрами, сортирует координаты X и заполняет их попарно. Верхний конец ребра не включается: yMin ≤ y < yMax.

Цвета на экране — только отображение. Состояние клеток хранится в двумерном массиве JavaScript независимо от Canvas.
