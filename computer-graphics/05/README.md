# Практическая работа №5. Заполнение областей

## Запуск
Открыть `index.html` в браузере. Сборка, сервер и сторонние библиотеки не требуются.

## Многоугольник и логический растр
Растр имеет размер **40 × 30**. Состояние хранится отдельно от Canvas в двумерном массиве `grid`: `0` — пустая клетка, `1` — граница, `2` — заполненная клетка. Canvas используется только для визуализации. Координаты вершин задаются в объекте `shapes` в начале `app.js`. Замкнутость контура задаётся флагом `closed`.

Стороны контура растеризуются целочисленным алгоритмом Брезенхема. В интерфейсе доступны прямоугольник, треугольник, выпуклый пятиугольник, невыпуклый многоугольник, тест горизонтального ребра, тест строки через вершину и незамкнутый контур.

## Flood Fill
Реализована функция `floodFill(startX, startY)`. Используется **4-связность**: `(x+1,y)`, `(x-1,y)`, `(x,y+1)`, `(x,y-1)`. Обход выполняется явным стеком, поэтому рекурсия не используется. Множество `visited` не позволяет повторно обрабатывать одну клетку. Выход за границы проверяется до обращения к массиву. Клетки границы не закрашиваются.

Стартовую точку можно ввести в поля X/Y или выбрать щелчком по растру. Ползунок и кнопки «Шаг» позволяют просматривать сохранённый порядок посещения.

## Scanline Fill
Реализована функция `scanlineFill(points)`. Для каждой строки находятся пересечения с рёбрами, координаты X сортируются, затем интервалы заполняются попарно. Горизонтальные рёбра пропускаются. Используется правило `min(y1,y2) ≤ y < max(y1,y2)`: нижняя граница включается, верхняя исключается. Для целочисленных координат заполнения применяются `ceil(xStart)` и `floor(xEnd)`.

Таблица выбранной строки показывает `y`, координаты пересечений X и интервалы заполнения.

## Обязательные тесты и ожидаемые наблюдения
1. **Прямоугольник** — оба алгоритма заполняют внутреннюю область при корректной стартовой точке.
2. **Треугольник** — Scanline вычисляет меняющиеся по строкам интервалы; Flood Fill распространяется от seed.
3. **Выпуклый многоугольник из 5 вершин** — оба метода работают с замкнутой границей.
4. **Невыпуклый многоугольник** — Scanline может получить несколько пар пересечений на одной строке; заполнение выполняется по каждой паре.
5. **Горизонтальное ребро** — горизонтальное ребро не добавляется в список пересечений Scanline, но остаётся видимым контуром.
6. **Строка через вершину** — правило полуоткрытого интервала предотвращает двойной подсчёт вершины.
7. **Flood Fill со стартом внутри** — заполняется связная внутренняя область.
8. **Flood Fill со стартом снаружи** — при замкнутом контуре заполняется внешняя область, ограниченная краями растра; это ожидаемо, поскольку алгоритм ориентируется на границу, а не на геометрическое понятие «внутри».
9. **Незамкнутый контур** — Flood Fill может пройти через разрыв и заполнить внешнюю часть растра. Scanline для разомкнутого контура в этой учебной реализации не выполняет заполнение, так как многоугольник должен быть замкнут.

Для проверки выберите соответствующую фигуру, алгоритм и нажмите «Выполнить». Тесты интерактивны: стартовая точка и строка Y доступны для изменения.

## Сравнение методов
Сравнение запускается кнопкой «Сравнить методы». Выполняется серия из 100 запусков каждого алгоритма; отображаются среднее время одного запуска, число обработанных элементов и количество заполненных клеток. Значения времени зависят от браузера и устройства, поэтому они измеряются при запуске, а не приводятся как заранее фиксированные числа.

| Метод | Нужна стартовая точка | Использует список вершин | Что обходится |
|---|---|---|---|
| Flood Fill | Да | Нет (работает по растру и границе) | Соседние пиксели |
| Scanline Fill | Нет | Да | Строки и рёбра |

## Вывод
Flood Fill требует seed-точку и использует обход связной области по соседним пикселям. Scanline Fill не требует seed и использует геометрию многоугольника: пересекает горизонтальные строки с рёбрами и заполняет интервалы попарно. При разрыве границы Flood Fill может выйти из предполагаемой внутренней области. Scanline в этой реализации не заполняет незамкнутый контур. Различия на границе связаны с тем, какие концы рёбер включаются, как обрабатываются вершины и как вещественные координаты округляются до целых пикселей.
