## Как используется симметрия окружности

Если для окружности с центром в начале координат найдена точка `(x, y)`,
то ей соответствуют ещё семь точек:
( x, y)
( y, x)
(-x, y)
(-y, x)
( x, -y)
( y, -x)
(-x, -y)
(-y, -x)


## Почему достаточно строить одну восьмую

Из-за симметрии все восемь октантов окружности получаются отражением
одного сектора.


## Что означает переменная d

`d` — решающая переменная (решающая величина). Она показывает, с какой
стороны от идеальной окружности находится средняя точка между
кандидатами `E = (x + 1, y)` и `SE = (x + 1, y − 1)`.


## Когда уменьшается y

`y` уменьшается только в ветви `SE`, то есть когда `d >= 0`.
В ветви `E` (`d < 0`) `y` остаётся прежним.


## Почему цикл заканчивается при x > y

Мы строим только один сектор — от верхней точки примерно до `45°`.
На границе сектора `x = y`. После этого следующие точки являются
отражением уже построенных, и продолжать вычисления нет смысла.


## Совпали ли пиксели алгоритма средней точки и способа через формулу

В большинстве случаев наборы пикселей совпадают. Кнопка «Сравнить»
показывает это для текущих `cx, cy, r`. 


## Что показал небольшой эксперимент по времени

Кнопка «Сравнить» выполняет серию из 50 прогонов каждого способа и
показывает среднее время. Обычно midpoint стабильно не медленнее
(а часто быстрее), потому что не вызывает `Math.sqrt` и работает
только со сложением/вычитанием/сравнением. Вывод нужно делать по серии
запусков, а не по одному замеру.
