2. Почему показатели лучше вычислять из массива, а не хранить отдельно?
Потому что отдельно хранимые счётчик, сумма, минимум и максимум — это
производные данные. Они всегда могут быть получены из массива.
Если хранить их отдельно, придётся синхронизировать пять значений при
каждой операции (добавление, удаление, очистка), и любая забытая
синхронизация приведёт к расхождению: например, в списке 3 числа,
а счётчик показывает 4.

3. Что возвращает getStatistics()?
Функция получает массив и возвращает объект с пятью свойствами:
{
  count: 3,
  sum: 42,
  min: 5,
  max: 25,
  average: 14
}

Функция ничего не знает о DOM, кнопках или HTML — она только считает
и возвращает результат. 

4. Как программа обрабатывает пустой массив? 
Для пустого массива getStatistics() возвращает объект со счётчиком 0
и остальными значениями null: { count: 0, sum: null, min: null, max: null, average: null }

5. Какое место в программе было сложнее всего отладить?
