
1. Где хранится состояние
Состояние программы — это одна переменная `value` в файле `app.js`.
Она объявлена через `let`, потому что её значение меняется при нажатиях.

2. Какая функция обновляет интерфейс
Функция `render()`.
Она читает текущее значение `value` и приводит DOM в соответствие с ним:
записывает число в `#value`, навешивает класс-состояние
(`positive` / `negative` / `zero`) и выводит текст в `#message`.

3. Какие события обрабатываются

Три события `click`:

    1. `#increase` → `value += 1`
    2. `#decrease` → `value -= 1`
    3. `#reset`    → `value = 0`

Каждый обработчик сначала изменяет `value`, а затем вызывает `render()`.

4. Что произойдёт, если изменить value, но не вызвать render()
На экране ничего не изменится.
Переменная `value` уже будет хранить новое число, но DOM об этом «не узнает»: в HTML-элементе `#value` останется старое значение,
класс-состояние не переключится, сообщение не обновится.
