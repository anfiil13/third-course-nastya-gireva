# Задание 5. Собственный REST API на Node.js и Express

**Сущность:** книги (каталог библиотеки).

Каждая книга имеет поля:

| Поле        | Тип     | Описание                              |
|-------------|---------|---------------------------------------|
| `id`        | number  | уникальный идентификатор (генерируется сервером) |
| `title`     | string  | название                              |
| `author`    | string  | автор                                 |
| `genre`     | string  | жанр (используется для фильтрации)    |
| `year`      | number  | год издания                           |
| `available` | boolean | есть ли книга в наличии               |

Данные хранятся в памяти (массив в `server.js`): при перезапуске сервера добавленные книги пропадают.

## Установка

```bash
cd internet-technologies/05
npm install
```

## Запуск

```bash
npm start
```

Сервер стартует на порту из переменной окружения `PORT`, по умолчанию — `3000`:

```bash
# Linux / macOS
PORT=4000 npm start

# Windows PowerShell
$env:PORT=4000; npm start
```

## Маршруты

| Метод | URL               | Описание                                   | Коды ответа   |
|-------|-------------------|--------------------------------------------|---------------|
| GET   | `/api/info`       | Название API, версия, количество книг      | 200           |
| GET   | `/api/books`      | Все книги или отфильтрованные по query     | 200, 400      |
| GET   | `/api/books/:id`  | Одна книга по id                           | 200, 404      |
| POST  | `/api/books`      | Добавить книгу                             | 201, 400      |
| *     | любой другой путь | Неизвестный маршрут                        | 404           |

### Query-параметры для `GET /api/books`

| Параметр    | Пример              | Что делает                                  |
|-------------|---------------------|---------------------------------------------|
| `genre`     | `genre=роман`       | точное совпадение жанра (без учёта регистра) |
| `author`    | `author=булгаков`   | поиск по части имени автора                 |
| `available` | `available=true`    | только в наличии (`true`) или нет (`false`) |
| `yearFrom`  | `yearFrom=2000`     | год издания не раньше указанного            |
| `yearTo`    | `yearTo=2020`       | год издания не позже указанного             |

Фильтры можно комбинировать. Без параметров возвращается вся коллекция.

## Примеры запросов

> В Windows PowerShell используйте `curl.exe` вместо `curl`. Русские буквы в URL
> лучше передавать закодированными (например, `роман` → `%D1%80%D0%BE%D0%BC%D0%B0%D0%BD`)
> или проверять запросы в браузере / Postman.

```bash
# Информация об API
curl http://localhost:3000/api/info

# Вся коллекция
curl http://localhost:3000/api/books

# Одна книга
curl http://localhost:3000/api/books/3

# Несуществующая книга -> 404
curl http://localhost:3000/api/books/99

# Фильтр по жанру (genre=фантастика)
curl "http://localhost:3000/api/books?genre=%D1%84%D0%B0%D0%BD%D1%82%D0%B0%D1%81%D1%82%D0%B8%D0%BA%D0%B0"

# Комбинация фильтров: книги 2000–2020 годов в наличии
curl "http://localhost:3000/api/books?yearFrom=2000&yearTo=2020&available=true"
```

### Корректный POST

```bash
curl -X POST http://localhost:3000/api/books \
  -H "Content-Type: application/json" \
  -d '{"title":"Улитка на склоне","author":"Аркадий и Борис Стругацкие","genre":"фантастика","year":1966}'
```

Ответ `201 Created`:

```json
{"id":8,"title":"Улитка на склоне","author":"Аркадий и Борис Стругацкие","genre":"фантастика","year":1966,"available":true}
```

### Некорректный POST (нет обязательных полей)

```bash
curl -X POST http://localhost:3000/api/books \
  -H "Content-Type: application/json" \
  -d '{"title":"Без автора","year":2020}'
```

Ответ `400 Bad Request`:

```json
{"error":"Некорректные данные","details":["Поле author обязательно (непустая строка)","Поле genre обязательно (непустая строка)"]}
```

Обязательные поля: `title`, `author`, `genre` (непустые строки), `year` (целое число).
Поле `available` необязательное, по умолчанию `true`.
